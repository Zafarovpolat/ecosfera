# Экосфера

Лендинг загородного отдыха «Экосфера» — 40 минут от Владивостока.

Статическая вёрстка: HTML, CSS и ванильный JavaScript. Без фреймворков,
без сборщика, без единой зависимости в `node_modules`. Node нужен только для
того, чтобы склеить `index.html` из секций.

**Живая версия:** https://zafarovpolat.github.io/ecosfera/

---

## Быстрый старт

```bash
npm run dev     # http://localhost:3000, пересборка на каждое обновление вкладки
npm run build   # собрать index.html
```

Оба скрипта — это `node build.mjs` и `node dev.mjs`. `npm install` делать не нужно:
зависимостей нет.

## Структура

```

src/
  template.html     каркас документа: <head>, порядок секций, подключение скриптов
  partials/         14 секций страницы, по файлу на секцию

css/
  tokens.css        дизайн-токены: цвета, шрифты, типографика, отступы
  base.css          сброс, базовая типографика, общие примитивы
  01…14-*.css       по файлу на секцию, имена совпадают с партиалами
  15-reveal.css     появление блоков при скролле

js/
  smooth-scroll.js  плавный скролл поверх Lenis
  reveal.js         наблюдатель за попаданием секций во вьюпорт
  reveal-in.js      сценарии появления элементов
  gallery.js        галерея фотографий
  comparison.js     блок сравнения
  reviews.js        карусель отзывов
  faq.js            аккордеон вопросов
  booking.js        форма бронирования
  lib/lenis.min.js  инерционный скролл

images/  icons/  fonts/
```

## Как это собирается

`src/template.html` — обычный HTML с двумя видами подстановок:

| | |
|---|---|
| `<!--@include 05-houses-->` | вставляет `src/partials/05-houses.html` |
| `{{v}}` | метка версии в адресах CSS и JS, сбрасывает кеш браузера |

`build.mjs` разворачивает включения (в том числе вложенные — шапка вставляется
внутрь hero), подставляет метку версии и пишет `index.html`. Отступ строки с
плейсхолдером переходит на вставляемый блок, поэтому diff собранного файла
остаётся читаемым.

## Как вносить правки

Разметку правим **в `src/partials/`, а не в `index.html`** — собранный файл
перезаписывается при каждой сборке. После правки:

```bash
npm run build
git add -A && git commit -m "…"
```

Стили секции лежат в одноимённом файле в `css/`. Новая секция — три шага:
партиал в `src/partials/`, `<!--@include …-->` в `src/template.html`,
CSS-файл в `css/` и ссылка на него в `<head>` шаблона.

## Дизайн

Все значения — цвета, размеры, интервалы, тени — вынесены в `css/tokens.css`
и взяты из Figma-макета. Подбирать оттенок или отступ на глаз не нужно:
меняем токен, и правка расходится по всей странице.

Адаптив построен на `clamp()` и медиазапросах, макет тянется от 375 до 1920.

## Деплой

Пуш в `main` запускает `.github/workflows/deploy.yml`: сборка, проверка на
битые ссылки, публикация на GitHub Pages. Ручной запуск — через Actions →
Deploy → Run workflow.

## Форма бронирования

Работает на фронте: шаги, валидация, подсчёт стоимости. Бэкенда нет —
отправка данных пока никуда не уходит.
