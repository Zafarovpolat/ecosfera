# Экосфера — 1:1 реконструкция макета

Лендинг [«Экосфера»](https://ecosfera-ruso.tilda.ws/), пересобранный из Figma-макета
в самостоятельный код без Tilda.

**Живая версия:** https://zafarovpolat.github.io/ecosfera/

---

## Что здесь

| | |
|---|---|
| Источник истины | Figma «Экосфреа» — фреймы `Главная` (1920×12699) и `Адаптив` (375×11520) |
| Десктоп | 12 секций, 620 узлов, 225 текстовых блоков |
| Мобайл | 11 секций, 532 узла, 189 текстовых блоков |
| Ассеты | 43 растра (3,8 МБ, WebP) + 49 SVG-иконок + 6 шрифтов |
| Вес страницы | 237 КБ HTML + 2 КБ CSS |

Вся геометрия, цвета, типографика и эффекты взяты из Figma через API — ни одно
значение не подбиралось на глаз.

## Как это устроено

Макет — это **фиксированный холст с абсолютным позиционированием** (ровно та же
модель, что у Tilda Zero Block, из которого сделан оригинал). Поэтому
соответствие 1:1 достигается пропорциональным масштабированием холста, а не
перевёрсткой:

```
--sd = clientWidth / 1920   (десктоп)
--sm = clientWidth / 375    (мобайл)
```

Множитель выставляется блокирующим inline-скриптом до первой отрисовки, поэтому
при загрузке ничего не «прыгает». Переключение холстов — на 768px.

Так текст не переносится иначе, чем в макете, ни на одной ширине экрана — именно
это и означает «строго 1 к 1» для канвасного дизайна.

## Структура

```
src/
  app/
    layout.tsx        шрифты, метаданные, скрипт масштаба
    globals.css       токены из UI KIT + примитивы холста
    page.tsx          два холста
  components/generated/
    desktop/          D* — по компоненту на секцию
    mobile/           M* — то же для 375
  fonts/              CoFo Sans, Forma DJR Display, CoFo Robert
  lib/asset.ts        префикс basePath для GitHub Pages
public/
  images/  icons/  fonts/
tools/                конвейер Figma → код (см. ниже)
spec/                 извлечённая спецификация макета
dist/                 собранная статика (то, что отдаёт Pages)
```

## Конвейер

Воспроизводимый путь от макета до кода. Требует Figma-токен в `FIGTOK`.

```bash
node tools/extract.mjs    # Figma API → spec/*.json (геометрия, краски, текст)
node tools/assets.mjs     # растры + экспорт иконок в SVG
python3 tools/crop.py     # нарезка каждого использования → WebP по месту
node tools/emit.mjs       # spec → TSX-компоненты + dist/
```

Про `crop.py`: Figma кодирует кроп как `scaleMode: STRETCH` плюс матрицу
`imageTransform`, и один мастер может обслуживать несколько разных кропов
(`image-35` — спрайт-лист из шести ячеек). Скрипт режет каждое использование в
отдельный файл нужного размера, поэтому в CSS не остаётся никакой математики
кропа. Это дало 88 МБ → 3,8 МБ без потери детализации.

`tools/lib-render.mjs` — общее ядро рендера: и TSX-компоненты, и статика
собираются из него, поэтому два выхода не могут разойтись.

## Разработка

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # статический экспорт в out/
```

`dist/` открывается напрямую, без сборки — это обычная статика.

## Деплой

Сайт отдаётся из ветки `gh-pages`, где лежит содержимое `dist/`.

Workflow `.github/workflows/build.yml` на каждый push в `main` проверяет,
что исходники проходят типизацию, линт и статический экспорт. Публикация
намеренно вынесена в ручной запуск (Actions → Build → Run workflow →
Publish), чтобы push не мог молча заменить рабочий деплой сломанным.

## Отличия от макета — сознательные

- **Цены.** В макете три ценника набраны разными семействами (`BravoSC`,
  `Helvetica Neue`, `Atyp Display`), причём для одной и той же цены на
  десктопном и мобильном фреймах по-разному. Это расхождение внутри самого
  макета, а не замысел, — все приведены к фирменному `Forma DJR Display`.
- **Мокапы.** `Yandex Sans Text` (текст согласия) → `CoFo Sans`;
  `SF Pro Text` (статус-бар телефона в мобильном фрейме) → системный шрифт.
- **Формы** визуально точны и интерактивны, но не подключены к бэкенду.
