# Экосфера — тема WordPress

Полный перенос лендинга [zafarovpolat.github.io/ecosfera](https://zafarovpolat.github.io/ecosfera/) в классическую тему WordPress. Вёрстка, стили, скрипты и ассеты те же; контент и заявки живут в админке.

## Установка

1. Скопируйте эту папку в `wp-content/themes/ecosfera`  
   (или загрузите ZIP через «Внешний вид → Темы → Добавить»).
2. Активируйте тему **Экосфера**.
3. При активации тема сама создаст:
   - главную страницу и включит «статическую главную»;
   - страницы Оферта / Политика / Соглашение;
   - два дома, отзывы и FAQ из макета;
   - меню шапки с якорями секций.

Плагины не нужны. PHP 8.0+, WordPress 6.4+.

## Где что править

| Что | Где |
|---|---|
| Телефон, почта, Instagram, Max, адрес, карта, герой, юр. текст | Внешний вид → Настроить → **Экосфера** |
| Преимущества, «рядом», включено/доплата, сравнение, аудитория, галерея | Меню **Экосфера** |
| Дома, цены, фото, удобства | **Дома** |
| Отзывы | **Отзывы** (заголовок = имя, текст = отзыв, миниатюра = аватар) |
| Вопросы | **FAQ** |
| Заявки с формы | **Заявки** + письмо на email администратора (или поле «Email для заявок») |
| Логотип | Настроить → Идентификация сайта |
| Меню | Внешний вид → Меню (Шапка / Подвал) |

## Форма брони

Заявка уходит AJAX-ом, пишется как запись типа «Заявка» и дублируется письмом. Предоплата на сайте не списывается — как в исходном лендинге.

## Структура

```
style.css           паспорт темы
functions.php
header.php footer.php front-page.php page.php 404.php index.php
inc/                setup, CPT, кастомайзер, настройки, бронь, сиды
template-parts/     секции лендинга 1:1 с исходными партиалами
assets/css|js|images|icons|fonts
```

Исходный статический сайт в корне репозитория не затронут.
